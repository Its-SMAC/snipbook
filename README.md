A simple local web application to save and manage code snippets.

## About the Project

This project was inspired by [Pastebin](https://pastebin.com/) , but aims to provide useful features for developers who want to quickly store and share reusable code.

## Where the idea was born

This idea was born from a need. When I was searching for code to help me with my projects, I often couldn't find exactly what I needed. So, I decided to build my own place to save and share useful code.


## Features

### v1

- Save code snippets
- Syntax highlight
- up-vote feature

### v2 (future)

- Deploy app
- Add comments
- Share snips
