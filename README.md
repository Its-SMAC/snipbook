# SnipBook
A simple web application to save, manage, and share code snippets with your team or community.

## About the Project

This project was inspired by Pastebin, but aims to provide useful features for developers who want to quickly store and share reusable code.

## Features

- Save code snippets
- Share snippets via link
- Syntax highlighting
- Public / private snippets (planned)
- User accounts (planned)

## Tech Stack

| Layer    | Technology       |
| -------- | ---------------- |
| Backend  | GO (Gin)         |
| Frontend | React            |
| Database | Supabase         |
